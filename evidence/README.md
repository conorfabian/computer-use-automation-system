The human run records HUMAN ownership, the operator's actual Unlock session click, navigation to the savings form, and AUTOMATION ownership on resume. The operator signaled resume through the development conversation; that explicit signal was relayed to the waiting CLI. The browser click was performed by the human, not a test script.

Each run contains `events.jsonl`, `result.json`, and masked screenshots. Image/file references inside logs are repository-relative. The capability's provenance points to the successful discovery run; model response IDs are retained without raw model transcripts. Discovery coordinates are evidence only. Member identifiers and nicknames are references in the artifact and redacted in logs/results/screenshots.

The normal app briefly displays its loading state too; `SLOW_LOAD` may appear in normal-run recovery logs. It records the same bounded wait used for the deliberately delayed scenario. These original demonstration logs predate the review fix that records recovery completion only after the loading state disappears.
